# 维护会话标题

钩子提供当前会话的标题文件路径、且没有要求保护现有名称时，一旦理解用户的初始需求，就按钩子当前语言提示用写入文件的工具写一行三段式标题；不要等最终回复。写入工具完成后，`PostToolUse` 钩子会尽早同步；`Stop` 钩子保留补偿。后续只有阶段、主题或当前进展明显变化才覆盖写入，标题仍准确时不要重复写。

「初始需求」用短语概括用户最初要解决的问题，首次确定后保持不变；「当前进展」概括这轮正在做的事。中文格式为「状态｜初始需求｜当前进展」，自动状态从「聊天、摸底、方案、开发中、测试、修复、待确认、已完成、搁置」中选择。英文格式为 `Status | Initial request | Current progress`，自动状态从 `Chatting, Scoping, Planning, Building, Testing, Fixing, Awaiting confirmation, Completed, Paused` 中选择。闲聊或问答、不需要动手干活时状态用「聊天」（英文 `Chatting`），纯聊天会话第一轮也要写一次标题。标题只写这三段，工作树和无项目会话都不加前缀、目录名或项目名。

用户在界面中手动修改某一段后，后续标题意图继续更新其他未锁定段，不要尝试恢复用户改过的段。手动状态可以使用自动状态词表之外的文字；钩子负责识别并保护。

钩子明确说明名称来源未确认时，保留现有名称，不写标题文件。只写钩子给出的路径；不要直接改 Codex 数据库或向回复添加隐藏标记。
