# 维护会话标题

钩子提供当前会话的标题文件路径、且没有要求保护现有名称时，初次实质回复后按钩子当前语言提示写一行三段式标题；后续只有阶段或主题明显变化才覆盖写入。初始化期间可以预写，钩子会等初始名称稳定后再应用。标题仍准确时不要写。

「初始需求」用短语概括用户最初要解决的问题，后续保持不变；「当前进展」概括这轮正在做的事。中文格式为「状态｜初始需求｜当前进展」，状态从「摸底、方案、开发中、测试、修复、待确认、已完成、搁置」中选择。英文格式为 `Status | Initial request | Current progress`，状态从 `Scoping, Planning, Building, Testing, Fixing, Awaiting confirmation, Completed, Paused` 中选择。无项目会话不加入目录名或项目名。工作树前缀由钩子负责添加。

钩子明确说明名称来源未确认时，保留现有名称，不写标题文件。只写钩子给出的路径；不要直接改 Codex 数据库或向回复添加隐藏标记。
